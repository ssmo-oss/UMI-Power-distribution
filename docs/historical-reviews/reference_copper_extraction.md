# TI PMP21274 reference copper extraction

Source: TI TIDRTY5 archive, PMP21274_REVA.PcbDoc. Binary interpretation follows work/datasheets/altium_parser_pcb.cpp (official KiCad Altium parser). Generated by work/extract_reference_copper.py into work/datasheets/pmp_reference_copper.json.

All coordinates are millimetres in original Altium positive-Y-up convention, matching pmp_reference_geometry.json. No translation or reflection has been applied. Binary integer units multiply by 0.00000254 mm. Property dimensions in mil multiply by 0.0254 mm.

Retained:172 netted copper tracks,45 vias,5 copper fills,8 polygon definitions,9 copper-layer regions and9 corresponding shape-based regions. The two region representations describe the same objects and must not both be added. Regions include8 cleared poured copper objects and1 top-layer polygon cutout (kind1, null net). Noncopper mechanical/logo artwork is excluded. No unnetted copper tracks were excluded. No netted copper arcs exist.

Important: Regions6 net fields are65535 even for copper. Their polygon_index resolves the net from Polygons6. Such resolved records have net_inherited_from_polygon=true. Preserve holes_mm. Raw polygon definitions are pour boundaries, not cleared final copper. Prefer Regions6 geometry for exact copper preservation; layer mapping1=top,2=MID1,3=MID2,32=bottom. Via layer74 means multilayer; actual spans are fromlayer1,tolayer32.

Tracks are all ordinary tracks, not polygon outlines. Widths0.254–0.381mm. Vias comprise32 at0.508mm diameter/0.254mm drill and13 at1.27mm diameter/0.635mm drill. Fill rotation is retained separately and must be applied.

Validation: Every binary stream consumed exactly its length with expected record types. Both region encodings consumed exactly their complete subrecords (zero unparsed tail). All9 Regions6 polygons, including holes, pass Shapely validity. Original poured areas in mm²:top GND3400.561,V+339.288,SW_P204.517,NetC5_1 189.515,VOUT332.519;MID1GND4809.831,MID2GND4655.631,bottomGND4840.012. Cutoutarea2.768.
